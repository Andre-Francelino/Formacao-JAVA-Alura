## 📚 Sobre o Projeto

Este repositório reúne exercícios, exemplos práticos e projetos desenvolvidos durante meus estudos na **Formação Java da [Alura](https://www.alura.com.br/)**.

O objetivo é registrar minha jornada de aprendizado na linguagem Java, colocando em prática os conceitos apresentados nas aulas e desenvolvendo gradualmente minhas habilidades em lógica de programação, sintaxe da linguagem e programação orientada a objetos.

Além de servir como material de consulta e revisão, este repositório documenta minha evolução como desenvolvedor Java.

## 🎯 Objetivos de Aprendizado

Durante a formação, os estudos são direcionados ao desenvolvimento de conhecimentos como:

- Fundamentos e sintaxe da linguagem Java.
- Declaração e utilização de variáveis e tipos de dados.
- Operadores e expressões.
- Estruturas condicionais e de repetição.
- Organização e estruturação de código.
- Programação Orientada a Objetos (POO).
- Criação e utilização de classes e objetos.
- Encapsulamento e composição.
- Desenvolvimento de aplicações práticas.

## 📂 Estrutura do Repositório

O repositório está organizado em diretórios que representam os conteúdos e projetos desenvolvidos durante a formação.

| Diretório | Descrição |
|---|---|
| `sintaxe_basica` | Exercícios e exemplos relacionados aos fundamentos e à sintaxe básica do Java. |
| `sintaxe_variaveis_e_fluxo` | Estudos sobre variáveis, tipos de dados e fluxo de execução do programa. |
| `bytebank` | Projeto prático desenvolvido durante as aulas da formação. |
| `bytebank_composto` | Evolução do projeto Bytebank, explorando conceitos de composição. |
| `bytebank_encapsulado` | Projeto Bytebank com aplicação dos conceitos de encapsulamento. |

## 💻 Como executar os projetos

Para executar os exemplos e projetos deste repositório, é necessário ter o Java Development Kit (JDK) instalado em sua máquina.

**1. Clone o repositório:**

```bash
git clone https://github.com/Andre-Francelino/Formacao-JAVA-Alura.git
```

**2. Acesse a pasta do projeto:**

```bash
cd Formacao-JAVA-Alura
```

**3. Abra o projeto em sua IDE de preferência**, como IntelliJ IDEA, Eclipse ou Visual Studio Code.

**4. Localize a classe principal (`main`) do exercício ou projeto desejado e execute o programa.**
